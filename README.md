# Grammar Pro & Active Builder | English Learning System

Este es un ecosistema educativo interactivo desarrollado para la **Universidad Santa María (USM)** como parte de la Maestría en Ciencias de la Educación 2026.

## 🚀 Características

- **Teoría Avanzada:** Guía visual de los 5 tiempos verbales clave.
- **Gimnasio de Verbos:** Base de datos de 400 verbos con búsqueda en tiempo real.
- **Sentence Builder:** Constructor lógico de oraciones mediante bloques (S-V-C-M).
- **Práctica Interactiva:** 400 ejercicios con retroalimentación inmediata.
- **Examen de Certificación:** Generación de exámenes aleatorios y emisión de diploma digital.

## 💻 Instalación Local

1. Clona este repositorio.
2. Abre el archivo `index.html` en tu navegador preferido.
3. ¡Listo! No requiere base de datos externa ya que toda la lógica es JavaScript Vanilla.

## 🛠️ Tecnologías utilizadas

- HTML5 / CSS3 (Tailwind CSS)
- JavaScript Vanilla (Lógica Core)
- FontAwesome para iconografía.
