Presente Simple

Hábitos & Hechos

Describe rutinas diarias, verdades universales y situaciones estables.

Fórmula Afirmativa

Sujeto + Verbo(s/es) + Complemento + Modificador

Smart Hack

Usa la terminación -s/-es solo para He, She, It. Si usas el auxiliar de negación doesn't, el verbo pierde la "S".

Presente Progresivo

Acción en Curso

Para acciones que se están desarrollando en este preciso instante.

Fórmula Afirmativa

Sujeto + BE(am/is/are) + Verb-ING + Comp + Mod

Smart Hack

El gerundio -ING jamás va solo; siempre requiere del verbo TO BE actuando como motor auxiliar de la frase.

Pasado Simple

Acciones Finalizadas

Indica eventos puntuales que ya concluyeron de forma definitiva en el pasado.

Fórmula Afirmativa

Sujeto + Verbo-ED/Irregular + Complemento + Mod

Smart Hack

El auxiliar DID/DIDN'T es un imán temporal. Cuando aparece, el verbo vuelve a su forma base (infinitivo).

Pasado Progresivo

Acciones en Desarrollo en el Pasado

Para acciones que estaban sucediendo en un momento concreto de ayer.

Fórmula Afirmativa

Sujeto + WAS/WERE + Verb-ING + Comp + Mod

Smart Hack

Usa WAS para sujetos singulares (I, He, She, It) y WERE para sujetos plurales (You, We, They).

Futuro

Intenciones & Predicciones

Usa "Will" para decisiones rápidas y "Going To" para planes ya agendados.

Fórmulas Afirmativas

Will: Sujeto + WILL + Verbo Base + Comp + Mod

Going: Sujeto + BE + GOING TO + Verbo Base + C

Smart Hack

Si tienes pruebas de que algo pasará (ej: nubes negras), usa siempre Going To. Si es solo una sospecha, usa Will.

Estructura Universal (S-V-C-M)

Toda oración sólida en inglés sigue un patrón jerárquico inalterable:

S

Sujeto: El agente principal de la acción.

V

Verbo/Aux: La acción conjugada temporalmente.

C

Complemento: El objeto que recibe la acción.

M

Modificador: El contexto temporal o espacial.
